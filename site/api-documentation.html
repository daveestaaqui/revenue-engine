Programmatic Public Records API

The Surplus Docket REST API delivers structured, daily-refreshed tax deed surplus and excess proceeds datasets directly to law firm CRMs, legal research software, and custom automated pipelines.

Base Endpoint URL

https://surplusdocket.com/api/v1 HTTPS / JSON

All requests use standard HTTPS GET requests and return structured UTF-8 JSON. Cross-Origin Resource Sharing (CORS) is enabled on all endpoints.

GET /api/v1/feed.json

Returns the master consolidated multi-state public records dataset across all monitored Florida and Texas jurisdictions. 

curl -s "https://surplusdocket.com/api/v1/feed.json"

Integration Snippets & AI-Agent Pipelines

Standardized JSON schemas ready for automated Python scripts, Zapier webhooks, and autonomous AI agents.

Python 3 (Autonomous Ingestion & Agent Hook) AI Ready 
import requests
import json

# Ingest Daily 7:00 AM Normalized Court Feed
FEED_URL = "https://surplusdocket.com/api/v1/feed.json"
response = requests.get(FEED_URL, timeout=10)
docket_data = response.json()

# Filter High-Value Individual Claims (> $50,000 with institutional noise removed)
actionable_claims = [
    c for c in docket_data.get("records", [])
    if c.get("Est_Finder_Fee_USD", 0) >= 10000
]

print(f"[✓] Successfully ingested {len(actionable_claims)} priority recovery dockets.")
# Direct payload to downstream AI drafting agent or Clio CRM webhook...
