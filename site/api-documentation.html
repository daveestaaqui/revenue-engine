Production REST Endpoints

Complete reference for all 6 jurisdictional routes and system manifest endpoints.

GET /api/v1/feed.json

Returns the master consolidated multi-state public records dataset across all 6 monitored jurisdictions (Florida, Texas, Georgia, North Carolina, Tennessee, and California). 

curl -s "https://surplusdocket.com/api/v1/feed.json"
GET /api/v1/florida.json

Returns filtered Florida clerk of court tax deed surplus records governed by Fla. Stat. § 197.582. 

curl -s "https://surplusdocket.com/api/v1/florida.json"
GET /api/v1/texas.json

Returns filtered Texas district court registry excess proceeds records governed by Tex. Tax Code § 34.04. 

curl -s "https://surplusdocket.com/api/v1/texas.json"
GET /api/v1/georgia.json

Returns filtered Georgia county tax commissioner excess funds records governed by O.C.G.A. § 48-4-5. 

curl -s "https://surplusdocket.com/api/v1/georgia.json"
GET /api/v1/north-carolina.json

Returns filtered North Carolina judicial tax foreclosure surplus records governed by N.C.G.S. § 105-374 (including 10-day upset bid tracking). 

curl -s "https://surplusdocket.com/api/v1/north-carolina.json"
GET /api/v1/tennessee.json

Returns filtered Tennessee chancery court tax sale surplus proceeds records governed by T.C.A. § 67-5-2501. 

curl -s "https://surplusdocket.com/api/v1/tennessee.json"
GET /api/v1/california.json

Returns filtered California county tax collector defaulted excess proceeds records governed by Cal. Rev. & Tax Code § 4675. 

curl -s "https://surplusdocket.com/api/v1/california.json"
GET /api/v1/health.json

Health check endpoint returning system uptime, API version manifest, and verified active endpoints. 

curl -s "https://surplusdocket.com/api/v1/health.json"

Data Dictionary & JSON Record Schema

Standardized canonical field definitions across all 6 jurisdictional feeds, ensuring zero data transformation overhead.

Field Name Data Type Example Value Description & Statutory Role
docket_id String "2026-TD-004501" Official court case number, tax deed certificate number, or county clerk registry file ID.
state String (ISO-2) "FL" Two-letter state postal abbreviation (FL, TX, GA, NC, TN, CA).
county String "Palm Beach" County judicial district or municipal tax collector jurisdiction.
sale_date String (ISO-8601) "2026-08-18" Date the tax foreclosure auction was confirmed or deed recorded.
surplus_amount Float / Number 145000.00 Gross excess bid proceeds held in registry after satisfying taxes, interest, and auction costs.
statutory_fee_cap_pct String / Float "20%" Governing statutory contingency fee limit or practitioner compensation ceiling.
filing_deadline String (Date/Text) "2026-12-16" Jurisdictional cutoff date calculated with court holiday & weekend roll-forward rules.
lien_scrub_status String / Enum "CLEARED_INDIVIDUAL" Institutional encumbrance verification flag confirming senior mortgages do not exhaust the balance.
clerk_portal_url String (URL) "https://mypalmbeachclerk.com/casesearch?caseNumber=2026-TD-004501" Query-parameterized direct link to the official clerk docket or court case verification portal.

Code Integration Examples

Standardized JSON endpoints for Python scripts, webhooks, and practice management workflows.

Python 3 
import requests
import json

# Ingest Daily 7:00 AM EST Normalized Court Feed
FEED_URL = "https://surplusdocket.com/api/v1/feed.json"
response = requests.get(FEED_URL, timeout=10)
docket_data = response.json()

# Filter High-Value Individual Claims (> $50,000 with institutional liens removed)
actionable_claims = [
    c for c in docket_data.get("records", [])
    if c.get("Est_Finder_Fee_USD", 0) >= 10000
]

print(f"[✓] Successfully ingested {len(actionable_claims)} priority recovery dockets.")
# Pass records to CRM or local database...
