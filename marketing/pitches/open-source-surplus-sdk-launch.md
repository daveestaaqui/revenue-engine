# PRESS PITCH: Surplus Docket Releases 'OpenSurplus SDK v1.2.0': Open-Source Statutory Calculator, Python CLI & OpenAPI 3.1.0 Spec for Court Registries

### PITCH SUMMARY / HOOK
To eliminate opaque third-party 'finder fee' traps and standardize statutory deadline computation across state lines, Surplus Docket has released OpenSurplus SDK v1.2.0 under the MIT License—featuring a drop-in <surplus-statute-calculator> Web Component, a zero-dependency Python 3 CLI, and a machine-readable OpenAPI 3.1.0 specification covering 6 core state statutory regimes.

### EXPERT PERSPECTIVE & QUOTE
"Legal aid clinics, county clerks, and foreclosure defense counsel shouldn't have to rebuild statutory deadline and fee-cap calculators from scratch. By releasing OpenSurplus as an MIT-licensed Web Component and Python CLI backed by an OpenAPI 3.1.0 specification, any bar journal, law school clinic, or practice management pipeline can verify statutory windows and UPL fee limits in milliseconds." — Systems Engineering & Data Architecture Lead, Surplus Docket

### VERIFIED STATS & CITEABLE DATA
- Covers 6 core state statutory frameworks: FL (§ 197.582 / § 45.032), TX (§ 34.04), GA (§ 48-4-5), CA (§ 4675), NC (§ 105-374), and TN (§ 67-5-2501).
- Includes zero-dependency Custom Element (<surplus-statute-calculator>) with Shadow DOM isolation and zero tracking cookies.
- Provides direct Clio Manage and Filevine CRM intake field mapping plus CITATION.cff academic metadata.
- Backed by real-time empirical market intelligence across 504 verified court registry records totaling $26.0M+: https://surplusdocket.com/blog/posts/multi-state-surplus-market-intelligence-report.html
